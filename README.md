# Guia de Estudos — Python, Pandas, SQL e Contabilidade

## Sobre o projeto

Este projeto foi criado como parte do meu processo de aprendizagem utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O objetivo é organizar conteúdos, fontes, anotações, exercícios e aprendizados relacionados a Python, Pandas, SQL, análise de dados e aplicações na área contábil.

## Objetivos

* Desenvolver conhecimentos em Python;
* Aprender manipulação e análise de dados com Pandas;
* Desenvolver conhecimentos em SQL;
* Explorar automação e geração de relatórios;
* Aplicar os conhecimentos em situações relacionadas à contabilidade;
* Registrar erros, dificuldades e aprendizados ao longo do processo.

## Tecnologias e ferramentas

* Python
* Pandas
* SQL
* NotebookLM
* Excel
* Openpyxl
* GitHub

## Organização do projeto

* notas/ — anotações e materiais produzidos durante os estudos.
* exercicios/ — exercícios práticos e projetos desenvolvidos.
* prompts/ — prompts utilizados no NotebookLM para apoiar o processo de aprendizagem.

## Aprendizagem ativa

O processo de estudo utiliza o NotebookLM para consultar fontes, gerar perguntas, criar exercícios, revisar conceitos e apoiar a construção de materiais de estudo.

Além dos conteúdos estudados, o projeto registra dificuldades e erros encontrados durante a prática, permitindo acompanhar a evolução do aprendizado.
