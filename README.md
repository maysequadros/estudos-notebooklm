# Guia de Estudos — Python, Pandas, SQL e Contabilidade

## Sobre o projeto

Este projeto foi criado como parte do meu processo de aprendizagem utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O objetivo é organizar conteúdos, fontes, anotações, exercícios e aprendizados relacionados a Python, Pandas, SQL, análise de dados e aplicações na área contábil.

O projeto também registra dificuldades e erros encontrados durante os estudos, mostrando como esses desafios contribuíram para a construção do conhecimento.

## Objetivos

* Desenvolver conhecimentos em Python;
* Aprender manipulação e análise de dados com Pandas;
* Desenvolver conhecimentos em SQL;
* Explorar automação e geração de relatórios;
* Aplicar os conhecimentos em situações relacionadas à contabilidade;
* Utilizar o NotebookLM como apoio ao processo de aprendizagem;
* Registrar erros, dificuldades e aprendizados ao longo do processo.

## Aprendizagem ativa

O processo de estudo utiliza o NotebookLM para consultar fontes, gerar perguntas, revisar conceitos, criar exercícios e organizar materiais de estudo.

A aprendizagem não se limita à consulta das respostas. Os conteúdos são utilizados como base para a realização de exercícios práticos e para a identificação de dúvidas e dificuldades.

## Resultado do processo

O projeto reúne teoria, prática e registro das dificuldades encontradas durante o aprendizado.

A proposta é utilizar o NotebookLM não apenas como ferramenta para obter respostas, mas como apoio para pesquisar, questionar, testar conhecimentos, identificar erros e construir novos aprendizados.

Dessa forma, o GitHub funciona como um registro da evolução dos estudos e como um mini guia de consulta para conteúdos relacionados a Python, Pandas, SQL, análise de dados e aplicações na contabilidade.
