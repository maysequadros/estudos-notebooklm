# Glossário de Estudos

Este glossário reúne os principais conceitos estudados durante o projeto, com definições curtas para facilitar futuras revisões.

## Python

**Python** — linguagem de programação utilizada no projeto para manipulação de dados, cálculos, automação e desenvolvimento de análises.

**Variável** — espaço utilizado para armazenar um valor que pode ser utilizado posteriormente no programa.

**=** — operador utilizado para atribuição de valores.

**==** — operador utilizado para comparar dois valores.

**for** — estrutura de repetição utilizada para executar uma ação várias vezes.

**if** — estrutura condicional utilizada para executar uma ação quando determinada condição é verdadeira.

**iterrows()** — método do Pandas utilizado para percorrer as linhas de um DataFrame.

---

## Pandas

**Pandas** — biblioteca Python utilizada para manipulação e análise de dados.

**DataFrame** — estrutura de dados tabular do Pandas, organizada em linhas e colunas.

**Series** — estrutura unidimensional do Pandas, normalmente representando uma coluna de um DataFrame.

**Filtro** — condição utilizada para selecionar somente as linhas que atendem a determinado critério.

**groupby()** — método utilizado para agrupar dados de acordo com uma ou mais colunas.

**merge()** — método utilizado para combinar DataFrames a partir de uma ou mais colunas em comum.

**sort_values()** — método utilizado para ordenar os dados de acordo com uma coluna.

**notna()** — método utilizado para identificar valores que não são nulos.

---

## SQL

**SQL (Structured Query Language)** — linguagem utilizada para consultar e manipular dados em bancos de dados relacionais.
**SELECT** — define quais colunas ou informações serão retornadas pela consulta.
**FROM** — indica a origem dos dados utilizados na consulta.
**WHERE** — aplica condições para filtrar os registros.
**JOIN** — combina dados provenientes de tabelas ou estruturas relacionadas.
**ON** — define a condição utilizada para relacionar os dados em um `JOIN`.
**GROUP BY** — agrupa registros para permitir a realização de agregações.
**SUM()** — calcula a soma dos valores.
**COUNT()** — conta registros.
**AVG()** — calcula a média dos valores.
**ROUND()** — arredonda um resultado numérico para determinada quantidade de casas decimais.
**HAVING** — aplica condições aos resultados agrupados.
**ORDER BY** — define a ordem de apresentação dos resultados.
**LIKE** — pesquisa valores que correspondem a determinado padrão.
**NOT LIKE** — exclui valores que correspondem a determinado padrão.
**AS** — cria um apelido (alias) para uma coluna ou resultado.
---

## Excel e Openpyxl

**Excel** — ferramenta utilizada para organizar, visualizar e apresentar os resultados das análises.
**pd.ExcelWriter()** — recurso do Pandas utilizado para exportar DataFrames para arquivos Excel e criar diferentes abas.
**Openpyxl** — biblioteca Python utilizada para trabalhar com arquivos Excel, incluindo formatação e edição das planilhas.
**number_format** — recurso utilizado para definir o formato de apresentação de valores, como moeda.
---

## Análise de dados

**Análise de dados** — processo de organizar, transformar e interpretar dados para obter informações úteis.
**Conciliação** — comparação de informações provenientes de diferentes fontes para identificar correspondências e diferenças.
**Agregação** — operação que resume vários registros em informações consolidadas, como soma, média ou quantidade.
**Automação** — utilização de ferramentas ou programas para executar tarefas de forma automática, reduzindo atividades manuais.
---

## NotebookLM

**NotebookLM** — ferramenta utilizada neste projeto como apoio à aprendizagem ativa, permitindo consultar fontes selecionadas, fazer perguntas e organizar conhecimentos.
**Aprendizagem ativa** — processo no qual o estudante participa ativamente da construção do conhecimento por meio de perguntas, prática, revisão, resolução de problemas e análise dos próprios erros.
**Prompt** — instrução ou pergunta fornecida a uma inteligência artificial para orientar a resposta ou a tarefa desejada.
**Engenharia de prompts** — processo de elaborar, testar e aprimorar instruções para obter respostas mais úteis e adequadas ao objetivo.
---

## Aplicação na contabilidade

**Nota fiscal** — documento utilizado para registrar uma operação comercial ou prestação de serviço e suas informações fiscais.
**Conciliação bancária** — processo de comparar registros financeiros internos com movimentações bancárias.
**Fechamento contábil** — conjunto de procedimentos realizados para organizar, conferir e consolidar informações contábeis de determinado período.
**Relatório financeiro** — documento que organiza informações financeiras para facilitar análise e acompanhamento.
**Auditoria** — processo de análise e verificação de informações, registros ou documentos para identificar inconsistências e avaliar sua conformidade.
---

## Objetivo do glossário

O glossário funciona como um material de consulta rápida para futuras revisões e ajuda a relacionar os conceitos de programação e análise de dados com situações práticas da área contábil.
